# Prompts Históricos

Este diretório preserva os prompts entregues na trilha P0--P3 do motor de
treino. Cada arquivo em `opencode/` usa o prefixo sequencial
`NN-fase-item-slug.md`, que registra a ordem e o objetivo original do trabalho.

São registros históricos, não contratos arquiteturais nem instruções para
reexecutar implementações. Decisões, código e políticas vigentes são definidos
por `AGENTS.md`, `docs/EMBASAMENTO-CIENTIFICO.md`, `docs/ROADMAP.md` e os
testes. Quando houver divergência, essas fontes canônicas prevalecem.

Os prompts originais são preservados sem reescrita para manter a rastreabilidade
do trabalho entregue.
