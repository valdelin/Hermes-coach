# TUI — Código comentado

As cópias em `src/ui/` e `scripts/hermes_tui.py` deste diretório existem para
leitura e estudo. Cada uma tem um cabeçalho que identifica a origem; após esse
cabeçalho, o conteúdo é idêntico ao arquivo canônico.

| Código executável | Cópia de estudo |
|---|---|
| `scripts/hermes_tui.py` | `scripts/hermes_tui.py` |
| `src/ui/` | `src/ui/` |

Não edite estas cópias para alterar o produto. Modifique o arquivo em `src/` ou
`scripts/`, então regenere a respectiva cópia didática.
